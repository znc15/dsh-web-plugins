# Agent Note: 精简皮肤管理卡（开关 / 原皮 / Whale Song / 主题）

Status: implemented

## Problem

皮肤中心卡片膨胀成了一个设置工作台：背景遮蔽与模糊滑杆、输入卡模糊、气泡不透明度、支持分模式取色器的自定义主题编辑器，以及 Wallpaper Engine 面板。用户只想要皮肤管理本身：总开关、官方默认外观、Whale Song（鲸吟）和亮/暗主题切换。

## Decision

卡片现在只渲染总开关、「官方默认」外观、Whale Song（鲸吟）与亮/暗主题切换。目录册仍通过 v2 运行时加载全部已安装皮肤，但卡片把列表过滤为 `whale-song`；其他皮肤仍可被运行时加载并保留在安装/市场路径中，只是不出现在这个精简管理列表里。背景与自定义主题运行时桥仍在 host 侧/客户端侧保持接线：已持久化的自定义主题在换肤时仍会正确施加与停用，壁纸选择仍会清除，背景遮罩命名空间不受影响。收缩的只是卡片渲染面。

自定义主题编辑面板、背景滑杆与壁纸面板不再被卡片 import，客户端 bundle 将其 tree-shake 掉；其控制器与 host 设置保留以维持持久化。测试文件改名为 `tests/skin-center-card.spec.tsx`，断言精简表面及应用/恢复/主题切换行为。

## Alternatives considered

- 整体删除自定义主题功能：否决，因为经官方设置 schema 施加的已持久化自定义主题必须继续工作；只移除编辑器可保留该契约。
- 在运行时过滤目录册：否决，运行时必须保持通用目录加载器；卡片才是展示过滤层。
- 保留滑杆但藏进折叠面板：否决，用户要求只显示这四个项目。

## Consequences

- 卡片为四项：开关、官方默认外观、Whale Song、亮/暗主题切换。
- 应用 Whale Song 或恢复官方默认外观仍走原子切换、壁纸清除与自定义主题停用事务。
- 卡片描述与 README 配对现在只描述精简表面；背景与自定义主题桥被记录为 host/控制器侧。
- `skin-center-card.spec.tsx` 冒烟套件覆盖渲染、应用、恢复、使用中标记与总开关。
